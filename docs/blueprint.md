# **App Name**: Research Hub

## Core Features:

- Research Paper Upload: Enable users to upload research papers with metadata (title, authors, abstract, file).
- Advanced Search: Implement a search function allowing users to find research papers by keywords, author, and publication year.
- Categorization and Access Control: Allow admins to categorize research papers by discipline and set access levels (public/private).

## Style Guidelines:

- Primary color: Neutral gray (#F5F5F5) for a clean, academic feel.
- Secondary color: Light blue (#E3F2FD) to indicate interactive elements.
- Accent: Teal (#008080) for emphasis and call-to-actions.
- Use clear and professional fonts for readability.
- Clean and structured layout to facilitate easy navigation.
